# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/).

## [0.1.0] - 2026-11-14

### Added
- Interactive CLI: source path, output folder, confirmation.
- Android (Kotlin + WebView) project generation from embedded templates.
- Gradle build with cache reuse and APK export.
- Launchers for Windows (`run.cmd`, `run.ps1`) and Linux/macOS (`run.sh`).
- CI workflow, license and community documents.
