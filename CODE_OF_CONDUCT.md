# Code of Conduct

We want APK-Builder to be a welcoming project for everyone.

## Our standards

- Be respectful and constructive.
- Accept feedback gracefully and give it kindly.
- Focus on what is best for the project and the community.

## Unacceptable behavior

- Harassment, insults or discriminatory language
- Personal or political attacks
- Publishing others' private information

## Enforcement

Maintainers may remove comments, commits or contributors that violate this
code. Report problems by opening an issue or contacting
[JustRohams](https://github.com/JustRohams).
